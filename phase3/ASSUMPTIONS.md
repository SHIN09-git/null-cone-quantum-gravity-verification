# 假设、证明层级与物理适用范围

| 层级 | 假设或构造 | 它支持哪一步 |
| --- | --- | --- |
| 严格验证 · 纯数学 | 固定复 Hilbert 空间、完备正交基与固定外态。模型显式取两个可数标签族的平方可和序列。 | 恒等开放演化满足 Parseval 拼接，绝对和由两外态范数之积控制。即使单个外态的展开无限长，也适用此定理。 |
| 严格验证 · 明确构造 | 两组基态面积分别为 1 与 3。高斯中心为 3、宽度参数为 1，提升快度为 π。两组具有相同的权重。单侧翻转交换对应标签，双侧观测量为两腿共同翻转取负。 | 固定有界自伴面积、正高斯制备、保范满射提升、实际双边制备和有符号插入。换一条穷尽时，所有算符及参考态都保持固定。 |
| 严格验证 · 坐标表示 | 双边空间取基系数空间 ℓ²(B×B)，右标签对应共轭腿。真实有限矩阵分量为 ⟨eᵢ,C P eⱼ⟩。一般判据允许源、靶 Hilbert 空间的任意基和不同的标签集。 | 开边界元和闭合矩阵向量的范数由不同的求和判据控制。对 C=0，零向量存在；归一化到单位范数要求 C≠0。工程使用完备的基坐标模型，没有形式化抽象完备张量积的泛性质。 |
| 严格验证 · 数学定义 | 对正的连续线性 W，普通扩展正迹是所有有限正交归一族对角和的上确界，可取正无穷。有限维时等于 mathlib 的线性迹；对 C†C，等于任一完整基上的列范数平方和。 | 给出所用“迹”的可操作定义。仅有某个有符号插入的有限值并未给出普通正迹。 |
| 条件性成立 · 正下界 | 对同一 W 在整个所考察空间有 W≥cI，其中固定 c>0。 | 任意秩 N 的有限正交族重至少 cN；普通正迹有限等价于空间有限维。假如权重沿基序列降低到零，估计中的同一个 c 就无法使用。 |
| 条件性成立 · 闭合 | 固定 c、非零响应阈值 δ、同一插入、同一选定截断族。在可任意提高秩的小响应截断上独立取得单一有限下界。有限极限版本要求此类高秩截断与同一滤子的每个尾部相遇。 | 在无限维假设下会得到与下界不相容的负秩界。存在某个能复现参考数的穷尽无法提供要求的下界。 |
| 条件性成立 · 谱带 | 几何论证需给出面积谱带、偏差矩与权重的联系。有限秩投影可与面积不对易。右腿有面积本征坐标且二阶矩可和时，工程直接证明响应界；标量正测度版本也可核验。 | 工程证明从有限窄带覆盖、闭合不变子空间、带内及全局算符范数界、cI≤W≤I 和响应界，构造高秩低矩扩充并推出充分条件。压缩 W 的本征基用于计算实际迹，允许投影与 W 或中心化面积不对易。对一般连续谱的四维制备，仍须把实际矩、约化密度和谱测度识别起来。 |
| 条件性成立 · 另一充分条件 | 在同一 B(H) 上给定一个有限值的正线性泛函，且它在每个有限秩正交投影上的值复现几何权重。 | 泛函在 I 上的值约束普通正迹。引力理论实际提供这样一个泛函仍需独立证明。 |
| 严格验证 · 标量数学 | 取实 x，以 k=1,2,… 为正频径向模式，带相位 e^(−2ikx)，截断保留前 N 个模式。级数中的 Li₂ 按闭单位盘的幂级数定义。 | 可对每个实 x 严格求和并控制尾项；耦合展开在 x=0 取实变量导数。一般物理耦合取正值，因此完整振幅的三阶右极限也单独检查。 |
| 尚未核验 · 物理对应 | x=4ℏG_N/𝒜、指定 Gaussian 态、单个角谐波与极化、Wick 收缩和附着在零锥上的来源决定数学起点。四维局域剪切、约束代数、真空、边界项和有界/无界算符的物理定义域还需建立。 | 标量振幅有限只涉及指定制备和插入；一般可观测量、散射振幅及紫外完备性需另证。 |
| 存疑 · 原文逻辑 | （5.38）的切面等价是否独立保证最后一个自由指标求和时仍得到同一有限未切振幅，以及附录 E 如何独立实现普通闭合。 | 形式化说明哪些补充条件足够，也给出开放前提下的反例。原文完整四维引力理论的维数仍待判定。 |
