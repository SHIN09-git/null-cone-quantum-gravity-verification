# 显式前提与需要另证的条件

## 第二阶段 · 第 5.2 节

| 条件 | v1 的处理与本次判定 |
|---|---|
| 所选表示、时钟的定义域与非零准备 | §4.2 固定一个纯态扩张，§5.1 以非零投影准备初态并构造稠密集。单调二次型的谱极限作用于极限型定义域闭包 $M$；只要 $P_M\Omega\ne0$ 就可能取得某个非零有限读数，若要（5.19）概率趋 1 则需 $\Omega\in M$。脚注 18 点明（5.16）中的非对易概率估计属启发式；脚注 20 留下不同表示的等价性。**条件性成立**。 |
| 时钟限制面积、而非直接限制谱重数 | （5.21c、d）使用时钟与面积的谱投影相容、聚焦算符的正性和角向柯西不等式。给定这些前提则 $0\le\hat s\le s_*$。**严格验证**谱界推论，重数还可无限。 |
| 端面保范与虚快度、高斯宽度 | （5.22）–（5.25）。给定幺正 $U$ 和虚半周的引力准备识别，函数演算得到 $W=e^{-\hat s}f_b(\hat s)$。固定 $b,\ell,\sigma_s>0$ 后下界 $c>0$。**严格验证**算符关系；物理准备的识别**条件性成立**。 |
| 有限投影和相对快度的定义域 | （D.22、D.23）在未来端面与角面共轭空间的张量积内使用 $\mathrm{vec}(C_bP)$。$\hat s$ 在所选区间有界，所有有限投影均可使用。**严格验证**。 |
| 两侧剪切、真空及能量代价 | （5.33）–（5.36）、D.2 使用沿角面与仿射方向平滑的共同极化、线性化场、分离支集、自由高斯真空和正规单模态。对光滑未切准备另要真空减除后为 $O(c_f/b^2)$、误差在所选尺度下受控。**条件性成立**；精确动力学的统一余项**尚未核验**。 |
| 闭合权重与收敛次序 | （5.38）前后将有限归一期望乘回权重，并要求整循环穷尽得到同一未切振幅。$P\to I$ 强成立仅保证固定外态间的开拼接，包括（4.29）。若直接要求普通双边准备有限范数，等价于 $W$ 迹类，依（5.30c）又等价于有限维。**存疑**这一步的独立引力依据。 |
| 替代性充分条件 | 对同一个 $X$ 独立给出截断无关的闭合极限，就能运行符号反证。有限维所需的最低证据还可缩为沿特别选取的整循环网有有限极限，因无限维会迫使它趋于负无穷。**严格验证**这两条蕴含。 |
| 公理性质与物理实例 | E.1 条件 5 要求紧能量支持下所有允许闭合有限；在有界提升谱上它包括恒等滤波。加上 E.3 的普通迹识别会直接给有限维。E.3 的（E.17）实际回用了（5.39c）。**条件性成立**其公理推论；精确引力是否独立满足此前提**尚未核验**。 |

各条件的证明、极限次序和模型是否满足原文物理要求，分别列在[逐式推导](DERIVATION.md)和[反例对照表](COUNTERMODEL.md)。
