# 核验结果

## 第二阶段 · 式（5.30c）至（5.39）

**存疑。** 已定位到（5.38）之后回引（4.29）的具体缺口。按普通双边界向量解释 $C_b$ 时，给它有限平方范数已经等价于要求有限维。若以独立的引力定义给未切标量赋值，还需要证明沿原文的整循环截断会得到该值。下表的判定分别针对可检验的数学步骤和将其用于精确引力的前提。[逐步推导](DERIVATION.md) · [v1 原文，第 41–43 页](https://arxiv.org/pdf/2611.34924v1#page=41)

| v1 公式 | 判定与证据 |
|---|---|
| （5.30c） | **严格验证**给定（5.21d）、（5.23）、（5.25）的算符不等式。紧区间上 $f_b$ 连续且有正最小值，故 $cI\le W=C_b^\dagger C_b\le I$。 |
| （5.31） | **严格验证**任一非零有限投影。有限双边界向量的平方范数恰为 $T_P=\operatorname{Tr}(PW)$，右腿约化态涉及 $PWP$ 的转置。 |
| （5.32） | **严格验证**通过谱定理和两单位向量期望差的不等式；与 $P$ 是否对易无关。窄带循环的（D.24、D.25）同样成立，连续谱也可以构造谱子空间的基。 |
| （5.33） | **严格验证**自伴源的正弦为有界算符；两侧可交换时乘积自伴。**条件性成立**零源混合导数识别剪切二点函数，需要二阶矩和相应定义域。 |
| （5.34） | **严格验证**在所用自由高斯场中，可选源使 $\delta_\eta\ne0$。独立计算分离点真空核、提升比和高斯正弦期望。精确引力的变化量要另控余项。 |
| （5.35） | **条件性成立**为线性化剪切的横向平滑及共同极化；还需仿射参数平滑，作用在所选局域场态上。 |
| （5.36a、b） | **条件性成立**。D.2 的正平方、单振子真空概率和 Cauchy–Schwarz 推出自由模型下的能量代价。未切侧的上界依赖光滑准备的重整化剪切、尺度层级和误差常数，**尚未核验**其非微扰版本。 |
| （5.37a、b） | **严格验证**移去半个真空信号的定义，以及无限维假定下有限循环一侧可使响应任意小。**条件性成立**未切一侧的严格正号，使用（D.36）。 |
| （5.38）及随后一段 | **严格验证**每个有限循环截断的符号。**存疑**同一未归一化振幅必须等于这些截断的极限。**发现反例**于由开拼接推出此闭合规律的推断。加强的循环估计甚至迫使相应 $Z_P[X]$ 趋于负无穷。 |
| （5.39a、b、c） | **严格验证**为给定 $0<\dim H<\infty$ 后的配分函数、密度算符与迹恒等式。**条件性成立**作为此四维引力空间的结论。原文全套引力前提下的无限维反例**尚未核验**。 |

**数值支持。** 在两面积模型中，硬截断按 1∶1 和 8∶1 纳入态，归一响应的精确值约为 0.00976179760628 和 0.00145199563146。固定 8∶1 的参数，改用指数滤波后得 0.00258132556705。计算覆盖 80 位与 130 位工作精度、两个面积中心和三种硬截断规模；存在性和发散性均另有解析证明。[模型与精确尾项](COUNTERMODEL.md) · [运行记录](REPRODUCIBILITY.md)

**条件性成立。** E.1 的谱滤波闭合有限加上 E.3 的普通计数迹，在有界提升谱上已足以推出有限维。E.2 的抽象重构从闭合公理起步。E.3 的引力实例（E.17）明确回引（5.39c）；将它倒过来用作 §5.2 的依据会构成循环。独立审查还检验了另一组无限维参数以及 §5.1 经典概率估计对非对易时钟的适用范围。[附录 E.1](https://arxiv.org/html/2611.34924v1#A5.SS1) · [独立反方审查](review/PHASE2_CN.md)
